# deployment/_shared/scripts — script index

Helpers placed here are shared across every per-target deploy under
`deployment/<platform>/<target>/`. Anything project-wide (keystore lifecycle,
secrets bootstrap, manual preflight) lives here; anything target-specific
(e.g. App Store upload helper) goes in the target's own folder.

> Contract (RULE-DEPLOYMENT-MANIFEST-001): scripts here MUST set `set -uo
> pipefail`, return non-zero on failure, and document inputs/outputs/exit
> codes below.
